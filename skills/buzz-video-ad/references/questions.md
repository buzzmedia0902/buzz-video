# 最初の質問（選択式）

素材を一通り見てから AskUserQuestion で聞く。ユーザーはスマホで選択肢を押して答えることが多いので、次のように書く。
- 選択肢は2〜4個
- 説明は1行
- 素材と目的に合うものを先頭に置き、ラベルの末尾に「（おすすめ）」を付ける

「その他」は自動で付くので、選択肢に入れない。

ユーザーがチャットですでに決めている項目（例：「縦で」「15秒で」）は聞き直さず、残りだけ聞く。

## 1回目（4問まとめて）

### Q1 テイスト（複数選択）
- header: `テイスト`
- question: `どのテイストで作りますか？（複数選べます）`

| label | description |
|---|---|
| スタンダード | ロゴとテロップで見せる王道の広告。20〜25秒 |
| モーション | テンポ速め・アニメーション多め。10〜15秒 |
| シネマティック | スロー・粒子感・縦書きの映画風。15〜25秒 |
| 口コミ風 | Vlogナレーション or LINE風トーク（次の質問で選択） |

医療（クリニック）・鍼灸・整骨では、4つ目を最初から次の文面にする（友だち同士の口コミは体験談にあたるため）。

| label | description |
|---|---|
| Q&A風（公式） | 院が設備や流れに答える形式。医療では口コミ風（体験談）の代わり |

おすすめの付け方：
- 人の表情や施術の流れがある素材 → スタンダード
- 素材が短い・カット数が多い → モーション
- 内装や光がきれい → シネマティック
- ロゴが淡い色（logo_prep.py が「pale logo」と出す） → 暗い画面で見せるシネマティック、またはエンドカードを暗くしたスタンダード

### Q2 アスペクト比（複数選択）
- header: `比率`
- question: `どの比率で書き出しますか？（複数可）`

| label | description |
|---|---|
| 9:16 縦 | リール・TikTok・ストーリーズ |
| 4:5 縦長 | Instagram／Facebookのフィード |
| 1:1 正方形 | フィード・カルーセル |
| 16:9 横 | YouTube・Webサイト・店頭モニター |

縦の素材ならふつうは 9:16 がおすすめ。横の素材なら 16:9 か 1:1 をおすすめにする。

### Q3 長さ
- header: `長さ`
- question: `長さはどうしますか？`

| label | description |
|---|---|
| おまかせ（おすすめ） | テイストごとに最適な長さ（モーション13秒前後、ほかは20〜24秒） |
| 15秒以内 | 広告で最後まで見られやすい長さ |
| 20〜25秒 | 流れをしっかり見せる |
| 30秒前後 | 説明やナレーションを多めに入れる |

使える素材の合計（映ってはいけない部分を除いた秒数）が短いときは、「15秒以内」をおすすめにして先頭に置く。目安は、使える素材が合計30秒未満、または使えるカットが6本未満のとき。同じ素材を何度も使うと、尺を伸ばしても間延びする。

### Q4 最後の導線（エンドカードの一言）
- header: `導線`
- question: `最後の画面で、見た人に何をしてもらいますか？`

業種に合わせて文言を変える。

| 業種 | 1（おすすめ） | 2 | 3 |
|---|---|---|---|
| 予約制（サロン・クリニック・整体） | ご予約はリンクから（Meta広告の予約ボタンにつながる） | プロフィールのリンクから（通常投稿向け） | LINEで予約・相談 |
| 飲食 | ご予約はリンクから | 詳しくはプロフィールへ | ご来店お待ちしています |
| 物販 | 詳しくはリンクから | 公式サイトをチェック | 店頭で試せます |

## 2回目（当てはまる質問だけ。最大4問）

### Q5 BGMの雰囲気（毎回聞く）
- header: `BGM`
- question: `BGMの雰囲気は？（すべてオリジナル曲を作曲します）`

| label | description |
|---|---|
| テイストに合わせる（おすすめ） | スタンダード=ピアノ、モーション=ポップ、シネマティック=ストリングス、口コミ風=ローファイ |
| やさしいピアノ | 落ち着き・清潔感（`piano`） |
| 明るいポップ | 軽快・元気（`pop`） |
| ゆったりローファイ | 会話や日常の雰囲気（`lofi`） |

ストリングス（`cinematic`）は「その他」で指定されたときにも使える。

### Q6 口コミ風の形式（Q1で「口コミ風」を選んだときだけ／複数選択）
- header: `口コミ風`
- question: `口コミ風はどの形式にしますか？`

| label | description |
|---|---|
| Vlog（ナレーション） | 「〇〇に行ってきた日」。AI音声と字幕で1日を語る |
| LINE風トーク | 行った人と行っていない人のトーク画面 |

医療（クリニック）・鍼灸・整骨では、友だち同士のトークは体験談にあたる。Q1で「Q&A風（公式）」を選んだ場合はこの質問を出さず、LINE風の画面で院が質問に答える形にする（Vlogも体験談の語りになるので使わない）。

### Q7 ナレーションの声（Vlogを選んだ、または選ぶ可能性があるとき）
- header: `声`
- question: `ナレーションの声は？`

| label | description |
|---|---|
| 落ち着いた女性（おすすめ） | AivisSpeech「morioki」。自然で無料、クレジット表記不要 |
| キャラクター声 | VOICEVOX。無料だが「VOICEVOX:キャラ名」の表記が必要 |
| より自然な声 | ElevenLabs（Higgsfield経由）。クレジットを消費 |
| 自分たちの声で録音 | 1文ずつ録音してもらう（line_01.m4a …） |

声の候補を具体的に見せたいときは `tts.py --list-speakers --engine aivis` で一覧を出す。

## 聞かずに決めてよいもの
次の項目は素材とロゴから決め、メモに書いて最後に伝える。
- 色：ロゴのアクセント色と、紙っぽい白・墨色
- フォント：上品なら明朝、親しみなら丸ゴシック
- キャッチコピー・タグライン：案を作り、報告で差し替えられることを伝える
- 書き出しの順番：まず1本・1比率を仕上げて共有し、残りを続けて作る
