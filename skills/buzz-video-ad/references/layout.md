# 比率とセーフゾーン

## 書き出しサイズ
| 比率 | サイズ | 主な置き場所 |
|---|---|---|
| 9:16 | 1080×1920 | リール、TikTok、ストーリーズ、ショート |
| 4:5 | 1080×1350 | Instagram／Facebookのフィード（フィード広告で一番大きく出る） |
| 1:1 | 1080×1080 | フィード、カルーセル、LINE VOOM |
| 16:9 | 1920×1080 | YouTube、Webサイト、店頭サイネージ |

フレームレートは30fps、映像はH.264（BT.709）、音声はAAC 256k・48kHz。

## セーフゾーン（文字とロゴを置ける範囲）
`core/canvas.py` の `SAFE` で設定している。`--guides` を付けた静止画では、黄色の枠が Meta、赤の枠が TikTok（9:16 のみ）を表す。

| 比率 | 上 | 下 | 左右 | 根拠 |
|---|---|---|---|---|
| 9:16（meta） | 14% | 35% | 6% | Meta のリール広告・ストーリーズの推奨（下35%はリールのUIとキャプション） |
| 9:16（tiktok） | 13% | 35% | 左11%・右17% | TikTok In-Feed。右側にボタン列がある |
| 4:5 | 6% | 10% | 6% | フィードの余白 |
| 1:1 | 6% | 8% | 6% | フィードの余白 |
| 16:9 | 7% | 15% | 5% | プレーヤーのUIが下に出る |

- TikTok 専用で配信するときは `"platform": "tiktok"` にする。横幅いっぱいのテロップは右のボタン列にかかる。
- 数値はプラットフォームの更新で変わる。審査で文字の位置を指摘されたら、Ads Manager のセーフゾーン表示で確かめる。

## テンプレート側の配置ルール（自作するときも同じ）
- 位置は `L.y(割合)` と `L.x(割合)` で指定する（0〜1 はセーフゾーン内の割合）。ピクセルで直接書かない。
- 比率ごとに値を変えたいときは `L.pick(tall=..., portrait=..., square=..., wide=...)` を使う。
- 縦に積む要素（エンドカードなど）は合計の高さを測り、収まらなければ小さく作り直す（`EndCard` は対応済み）。
- 1行の幅は `L.text_w` 以内にする。収まらないときは `E.fit_size()` で文字を小さくするか、文言を短くする。

## 素材の比率と出力の比率が違うとき
- **cover**：素材を出力の画面いっぱいに切り取る。`zoom` と `center` でどこを見せるか決める。
- **blur**：素材全体を中央の枠に置き、外側をぼかして暗くした同じ映像で埋める。縦の素材を16:9にするとき（cover だと素材の32%しか映らない）の既定で、render.py が警告を出す。
- 縦の素材から 4:5 や 1:1 を作るときは cover のままでよい（素材の56〜70%が映る）。ただし次の点を確認する。
  - 切り取る範囲が変わり、9:16 では画面の外にあったPOPや他社ロゴが見えることがある。比率ごとに静止画で確認し、`patches` を足すか `aspect` で `center` を変える。
  - 顔が上下で切れていないか。`"aspect": {"1:1": {"center": [0.5, 0.33]}}` のように直す。
- 16:9 で blur を使うと、文字は左右のぼかした部分にもかかる。読みやすさを静止画で確認する。

### 縦の素材から16:9
blur のままだと、中央に細い縦長の映像が出るだけで、広告としては弱い。ショットごとに `"aspect": {"16:9": {"fit": "cover", "center": [x, y]}}` を付けて横長に切り取るのが基本。
- 映るのは素材の高さの約32%（横長の帯）。`center` の y で、どの高さの帯を見せるか決める。グリッド（`grid.py`）で主役の高さを読む。
- 拡大率は 4K素材（縦2160×3840）なら約0.9倍で劣化なし。1080pの素材（1080×1920）では約1.8倍で少し甘くなるが、内装・小物なら見られる。
- テロップも横長の画面に合わせて `pos` と `x` を直す（例：左右どちらかに寄せる）。
- 人物のアップなど、横に切ると不自然になるショットは blur のままでもよい。
