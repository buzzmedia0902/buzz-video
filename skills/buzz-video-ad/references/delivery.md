# 納品

## フォルダ構成（project.json の out_dir。既定は `納品/`）
```
納品/
  SALON_SAMPLE_スタンダード_9x16_24秒.mp4          入稿用（高画質）
  SALON_SAMPLE_スタンダード_9x16_24秒_軽量版.mp4   スマホでの確認・共有用（30MB未満）
  SALON_SAMPLE_スタンダード_9x16_24秒_カバー.png    カバー画像（リールの表紙など）
  投稿文案.txt
  メモ.txt
```
- 名前は `<project>_<テイスト>_<比率>_<秒>秒` にする。同じテイストで複数案あるときは、version の `label` で区別する（例：`スタンダード15秒版`）。
- 作り直したときは、前の版を `納品/旧版/` に移してから上書きする。消さない。

## 途中経過の共有
- 最初の1本の書き出しが終わったら、すぐ軽量版を送る（SendUserFile があればそれで。なければファイルの場所を伝える）。30MB を超えるとスマホで見られないので注意する。
- 送るときは「残り◯本・あと約◯分」を一言添える。長い作業の途中で黙らない。

## 投稿文案.txt の型
```
【キャプション案】
<1行目：何の店か＋行きたくなる一言（効果の言い切りはしない）>
<2〜3行：雰囲気・こだわり・場所>
<導線：ご予約はプロフィールのリンクから／広告ではボタンに任せて省略>

【ハッシュタグ】
#<地名><業種> #<業種> #<店名> ...（5〜10個。効果をうたうタグは使わない）

【広告の見出し・説明文（Meta広告用）】
見出し：<20字前後>
説明：<30字前後>
```

## メモ.txt の型
```
【<案件名> SNS広告 <本数>パターン】
■ <テイスト>（<秒>秒・<比率>）<ファイル名>
  <狙い1行>
  <時刻> <内容> ... （構成表の主な場面）
  向いている場所：<リール／フィード／TikTok …>
■ 共通
  - BGMはすべてオリジナル作曲（既存の曲・音源は不使用）／音量 -14 LUFS
  - ぼかし処理：<何をぼかしたか>
  - 文字は Meta のセーフゾーン内
  - ナレーション：<エンジン・声>（<クレジット表記の要否>）
■ 配信前の確認事項
  - <業種の広告規制の注意点>（最終確認はクライアント・保健所など）
  - <審査リスク（年齢制限の推奨など）>
  - 出演者の掲載同意
```

## 送り方（頼まれたときだけ）
- **ZIP**：日本語のファイル名が Windows で文字化けしないよう、Python の `zipfile` で作る（UTF-8 のフラグが付く）。
- **ギガファイル便などの転送サービス**：大きいファイルの受け渡しに使う。アップロードはサービスの画面など公式の方法で行い、削除キーはチャットに書かない。
- **Googleドライブ**：rclone のリモート `gdrive:`（drive.file 権限）を使う。
  - アップロード：`rclone copy <フォルダ> "gdrive:<フォルダ名>"`
  - 照合：`rclone check <フォルダ> "gdrive:<フォルダ名>" --one-way`（MD5で照合）
  - 共有設定はユーザーがドライブ上で行う。
