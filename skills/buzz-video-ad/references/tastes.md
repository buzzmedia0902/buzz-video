# テイスト別の構成と項目

どのテイストもショットの書き方は共通（[spec.md](spec.md)）。長さは構成表から決まる。
- ショットの `dur` の合計
- 拍の数（モーション）
- ナレーションの長さ（Vlog）
- メッセージの数（トーク）

時刻を直接書く箇所はほとんどない。美容鍼サロンの実案件で作った作例（店名などは差し替え済み）は [../examples/salon/project.json](../examples/salon/project.json) にある。

各テンプレートの全項目と既定値は `scripts/tastes/<テイスト>.py` の冒頭（docstring）に書いてある。ここでは構成の考え方と最小の例だけを載せる。

## どのテイストにも共通の注意
- **カットの頭の余白**：ディゾルブなどの場面転換は、つなぎ目の前後で2つのカットを重ねて見せる。そのためカットは `in` より少し前（つなぎの長さの半分×速度。0.1〜0.2秒）から素材を使う。`in` が0に近いと「needs source -0.06…」というエラーになるので、`in` を少し後ろにずらすか、そのカットへのつなぎを `cut` にする。
- **淡い色のロゴ**（logo_prep.py が `NOTE: pale logo` と出したとき）
  - 明るいエンドカードの上では読めない。スタンダードは自動で暗いエンドカード（`"card": {"theme": "dark"}`）になり、ディゾルブで移る。明るいカードにしたいときは `"theme": "light"` を明示する。
  - 冒頭のロゴ（スタンダードの `hook_logo`、モーションの `"logo"`）は、素材の暗い部分（カーテン・家具・夜の窓など）に重なるように、1カット目と位置を選ぶ。スタンダードは淡色ロゴのとき後ろの影が濃くなる（`"hook_logo": {"halo": 0.75}` 相当）。
  - 暗い画面で見せるシネマティックとの相性がよい。
  - ロゴの中に半透明の部分（花びらの陰影など）があると、暗い背景ではまだらに見える。`logo_preview.png` の下段で確認し、気になるときはクライアントに暗い背景用のロゴデータ（白抜き版）がないか聞く。もらえたら `brand.logo` をそれに替えて `logo_prep.py --ink light` で作り直す。
- **縦の素材から16:9**：何も指定しないと「中央に素材＋左右ぼかし」になり、render.py が警告を出す。広告らしく見せるには、ショットごとに横長に切り取る。
  - `"aspect": {"16:9": {"fit": "cover", "zoom": [1.05, 1.0], "center": [0.5, 0.45]}}` のように書き、`center` の y で縦のどの帯を見せるか決める（素材の高さの約32%が映る）。
  - テロップの位置も `"caption": {"aspect": {"16:9": {"pos": ..., "x": ...}}}` で直す。
  - 4K素材ならきれいなまま。1080pの素材は約1.8倍の拡大で少し甘くなるが、内装・小物なら見られる。人の顔のアップは blur のほうが自然なこともある。

## standard — スタンダード（王道のブランド広告）
ゆっくり動くショットに、明朝の一言テロップを1文字ずつ浮かび上がらせる。
- 構成：日常 → きっかけ → 体験 → 笑顔 → ごほうび → ロゴ。
- 1カット目：ロゴと英字ラベルを添えた大きな一言（フック）。
- つなぎ：カットのつなぎ目は、カット／ディゾルブ／フラッシュ／ホワイトアウトから選ぶ。
- 締め：ホワイトアウトで明るいエンドカードへ移る。エンドカードには、浮かぶ粒子・ラベル・ロゴ（光が走る）・タグライン・枠線つきの導線ボタンが並ぶ。
  淡い色のロゴでは暗いエンドカードになり、ディゾルブで移る（`card.theme` で指定もできる）。
- BGMは `piano`。ロゴが光る瞬間にチャイムが鳴る。

```json
"standard": {
 "taste": "standard", "duration": 24, "fonts": {"latin": "optima"},
 "card": {"dur": 3.6, "transition": "whiteout", "tdur": 0.48},
 "shots": [
  {"clip": "IMG_2742.MOV", "dur": 1.8, "in": 2.85, "speed": 0.5, "zoom": [1.42, 1.3], "center": [0.46, 0.36],
   "caption": {"rows": [{"text": "顔に、鍼。", "size": 140, "font": "title"}], "label": "BEAUTY ACUPUNCTURE", "pos": 0.297}},
  {"clip": "IMG_1454 2.mov", "dur": 1.8, "in": 7.5, "zoom": [1.4, 1.46], "grade": "daily", "transition": "cut",
   "caption": {"rows": ["画面と、", "にらめっこの毎日。"], "theme": "dark", "pos": "upper"}},
  {"clip": "IMG_1446 2.mov", "dur": 1.8, "in": 4.9, "grade": "daily", "transition": "cut",
   "caption": {"rows": ["ふと、", "頬に手がのびる。"], "pos": 0.88, "aspect": {"4:5": {"pos": "top"}, "1:1": {"pos": "top"}}}},
  {"clip": "IMG_0996.MOV", "dur": 2.4, "in": 3.4, "grade": "counsel", "transition": "flash", "tdur": 0.48,
   "caption": {"rows": ["あなたの顔を、", "知ることから。"], "label": "COUNSELING", "theme": "dark", "pos": "top"}},
  "...",
  {"clip": "IMG_1460 2.mov", "dur": 1.8, "in": 29.0, "grade": "daylight", "transition": "dissolve",
   "caption": {"rows": ["朝の光が、", "うれしくなる。"], "theme": "dark", "pos": "upper"}}]
}
```
- `transition`：そのショットへの入り方（cut / dissolve / flash / whiteout）。`tdur` はつなぎの長さ。
- `caption`：1ショットに1つ。
  - `rows`：1〜3行。最後の行が大きくなる。
  - `label`：上に添える英字（金色の小さな文字）。
  - `theme`：light（白文字）または dark（墨文字。明るいショット用）。
  - `pos`：top / upper / middle / lower / bottom、またはセーフゾーン内の割合。
  - `in` / `out`：出る時刻と消える時刻（ショットの頭からの秒／ショットの終わりまでの秒）。
- `duration` を指定すると、ショットの合計との差がエンドカードの長さになる（3.2〜6秒）。
- `card.theme`：light（既定）／dark（淡い色のロゴでは dark が既定）。
- `hook_logo`：true／false、または `{"variant": "on_light", "halo": 0.6}`。on_light は明るい背景用のロゴを淡い光の上に置く（明るい素材で墨色のロゴを見せるとき）。`halo` は後ろの影の濃さ（0〜1）。
- 色調整（grade）は daily（くすんだ日常）／ counsel（カウンセリング室）／ daylight（明るい締め）がこのテイスト向き。
- 4:5・1:1 では、人物が画面の中央寄りに来て顔にテロップがかかりやすい。テロップの位置を `"aspect": {"4:5": {"pos": "top"}}` で比率ごとに逃がす。

## motion — モーション（テンポ速め・アニメーション多め）
すべてを**拍（beat）**で数える。長さは拍の合計で決まる。`"duration": 20` を指定した場合は、合計の拍に合うようにBPMを逆算する。
構成：フック → ステップ（1〜n）→ 締め → エンドカード。BGMは `pop`。
- フック：金色の円が開き（アイリス）、ロゴとテロップの丸ボタンが拍に合わせて出る。
- ステップ：番号の円・STEP表示・見出し・補足が飛び出し、少しあとで左上の小さなチップに縮む。
  - ショットが複数のステップは、拍ごとのモンタージュになる。カットのたびにフラッシュ・ズーム・キラキラが入る。
  - 細部は `ring` で金色の輪を付けて強調できる（例：iPadの画面）。
- 締め：ごほうび系の一言。
- エンドカード：円形に開き、ロゴの文字が飛び出し、タグラインが出て、導線ボタンが拍に合わせて脈打つ。
- 退場のアニメーションは、各区切りの前に必ず終わる（カットで突然消えないように）。フラッシュの間隔は1/3秒以上あける（光の点滅の配慮）。

```json
"motion": {
 "taste": "motion", "bpm": 138.5,
 "hook": {"lines": [{"text": "顔に鍼って、", "style": "dark"}, {"text": "どんな感じ？", "style": "gold"}],
          "shot": {"clip": "IMG_2742.MOV", "in": 2.85, "speed": 0.5, "zoom": [1.4, 1.28], "center": [0.46, 0.36], "beats": 4}},
 "steps": [
  {"title": "カウンセリング", "sub": "お顔をじっくり確認",
   "shot": {"clip": "IMG_0996.MOV", "in": 3.0, "beats": 4,
            "cam_beats": [[0, 1.36, 0.42, 0.5], [1.9, 1.4, 0.42, 0.5], [2.6, 1.8, 0.4, 0.5], [4, 1.86, 0.4, 0.5]],
            "ring": {"at": [0.389, 0.495], "r": 0.125, "beat": 2.4}}},
  {"title": "施術", "sub": "横になって、おまかせ", "beats": 8,
   "shots": [{"clip": "IMG_2722.MOV", "in": 1.0, "speed": 0.5, "zoom": [1.25, 1.15], "center": [0.5, 0.42]}, "... 4ショットで8拍"]},
  {"title": "ほっと、ひと息", "badge_y": 0.644, "shot": {"clip": "IMG_2739.MOV", "in": 5.15, "speed": 0.5, "beats": 3}}],
 "closing": {"lines": [{"text": "がんばる毎日に、", "size": 50}, {"text": "ごほうびを。", "style": "gold", "size": 92}],
             "y": 0.27, "shot": {"clip": "IMG_1444 2.mov", "in": 8.2, "zoom": [1.4, 1.5], "beats": 3}},
 "card": {"beats": 8}
}
```
- 長さの目安：138BPM で30拍 ≒ 13秒、46拍 ≒ 20秒。
- エンドカードより前の拍数は**4の倍数**にする。そうするとBGMの小節がカットにぴったり合う。
- 比率ごとにテロップが顔にかかるときは、そのセクションに `"aspect": {"4:5": {"y": 0.40}}` を足して位置を変える。
- 明るい素材の上では白いロゴが見えなくなる。フックに `"logo": "on_light"`（濃い色のロゴ）を指定する。

## cinematic — シネマティック（スロー・粒子感・縦書き）
60fps素材のスロー映像を、約0.8秒のクロスフェードと光漏れでつなぐ。
- 映像の質感：フィルムの粒子、ハレーション（`cine` の色調整）、黒からのフェードイン。
- 文字：縦書きの一言が1文字ずつ現れる（例：ほどける。／ととのう。／わたしに、還る。）。章の印を付ける（I 静／II 整／III 還）。
- 締め：暗転して暗いロゴカードへ移り、導線は金色の罫線にはさんだ文字で出す。
- BGMは `cinematic`（ストリングス）。効果音は付けない。

```json
"cinematic": {
 "taste": "cinematic", "duration": 24,            // ショットの dur の合計を引いた残りがエンドカード（2.8〜8秒）
 "xfade": 0.8, "leak": 0.38, "grain": 0.035, "fade_in": 1.12,
 "shots": [
  {"name": "open", "clip": "IMG_2742.MOV", "in": 0.6, "dur": 3.2, "speed": 0.5, "zoom": [1.50, 1.40], "center": [[0.40, 0.33], [0.40, 0.32]]},
  {"name": "counsel", "clip": "IMG_0996.MOV", "in": 1.6, "dur": 3.2, "zoom": [1.36, 1.46], "center": [0.42, 0.50]},
  "...",
  {"name": "light", "clip": "IMG_1460 2.mov", "in": 29.1, "dur": 2.0, "zoom": [1.15, 1.10], "center": [0.45, 0.42]}],
 "lines": [{"text": "ほどける。", "shot": "open", "at": 0.72},
           {"text": "ととのう。", "shot": "wires", "at": 0.40},
           {"text": ["わたしに、", "還る。"], "shot": "light", "at": 0.1, "side": "left", "color": "ink",
            "aspect": {"4:5": {"side": "right"}, "1:1": {"side": "right"}}}],
 "chapters": [{"num": "I", "text": "静", "shot": "counsel"}, {"num": "II", "text": "整", "shot": "wires"}]
}
```
- `lines`（縦書きの一言）の書き方：
  - どのショットに出すかを `shot` で指定する（番号か name）。`at` はそのショットの開始からの秒、`until` はショットの終わりからの秒。
  - 配列で書くと、右から左へ複数列になる。
  - `side`：right / left / center
  - `top`：書き出しの高さ
  - `color`：white / ink / ブランド色
  - 「ー」「…」「（）」は縦書き用の字形に自動で置き換わる。
- `chapters`：左上に出す章の印。明るい素材の上では見えにくい。その比率だけ `"aspect": {"16:9": {"off": true}}` で消せる。
- 長さの目安：7ショット＋カード3.6秒 ≒ 24秒、5ショット ≒ 15秒。1ショットは `xfade + 0.5` 秒以上にする。
- **縦の素材から16:9を作る場合**：冒頭の「どのテイストにも共通の注意」のとおり、主役のショットは cover で横長に切り出すと映画らしくなる。

## chat — LINE風トーク（チャット画面）
「行った人（L）」と「まだ行っていない私（R）」のトーク画面。LINEのロゴ・名称は使わない。メッセージの並びだけ書けば、時刻・スクロール・効果音は自動で決まる。
- 画面の要素：
  - 実機どおりのステータスバー
  - ヘッダー
  - ロゴ入りのピン留めバナー
  - 吹き出しと既読・時刻
  - 素材が再生される動画メッセージ
  - オリジナルのスタンプ
  - 予約リンクのカード
  - 入力中の表示（…）
  - iOSのかなキーボード
- 最後のリンクカードにズームし、エンドカードへ移る。BGMは `lofi`（-5 dB）。
- 比率ごとの見せ方：
  - 9:16：全画面
  - 4:5：画面を詰めて表示（見える吹き出しは3つ程度）
  - 1:1：スマホの枠を置き、左右にタグラインとラベル
  - 16:9：スマホの枠を置き、横にラベル・ロゴ・タグライン
- 時刻はさかのぼらない。ステータスバーの時計は、最新のメッセージの時刻と常に一致する。
- 「※画面はイメージです」を既定で表示する（ステマ規制・体験談への配慮）。

```json
"chat": {
 "taste": "chat", "title": "あや", "banner": "美容鍼、気になってた？", "duration": 13,
 "end": {"tagline": "気になってたなら、いまが行きどき。", "theme": "light", "cta_style": "solid"},
 "beside": {"tagline": "がんばる自分に、ごほうびを。"},
 "messages": [
  {"side": "L", "kind": "video", "shot": {"clip": "IMG_2742.MOV", "in": 2.85, "speed": 0.5, "zoom": [1.45, 1.38], "center": [0.46, 0.38], "soft_below": 0.63}},
  {"side": "L", "text": "美容鍼いってきた〜！"},
  {"side": "R", "kind": "sticker", "text": "えっ！？"},
  {"side": "L", "kind": "typing"},
  {"side": "L", "text": "カウンセリングで\n相談できて安心だったよ"},
  {"side": "R", "text": "いいな〜！私も行きたい！"},
  {"side": "L", "text": "予約リンク送るね！"},
  {"side": "L", "kind": "link", "title": "SALON SAMPLE｜美容鍼のご予約"},
  {"side": "R", "text": "ありがと！"}
 ]
}
```
- 各メッセージで使えるキー：
  - `side`：L または R
  - `kind`：text / video / sticker / link / typing
  - `text`：改行は `\n`
  - `shot`：動画メッセージの素材
  - `dur`：動画の再生秒、入力中表示の秒
  - `face`：スタンプの表情（surprised / happy / love）
  - `t`：表示する秒を直接指定
  - `gap`：前のメッセージからの間
  - `clock`：時刻 "20:42"
- `duration` を指定すると、間が自動で伸び縮みする。
- 変更できる項目：
  - `clock`：最初の時刻
  - `minute_every`：何秒ごとに時刻を1分進めるか
  - `palette`：壁紙と自分の吹き出しの色
  - `zoom`：最後のズームをするか
  - `hold`：エンドカードの秒
  - `note`：注記
- 医療・鍼灸・整骨では体験談にあたる。L を店の公式アカウント（`title` を店名、`avatar` を頭文字）にして、設備や流れを答えるQ&A形式にする。
- 吹き出しが動画の上で長くなると見づらい。文は1〜2行（`\n` で区切る）にする。

## vlog — Vlog（ナレーション＋字幕）
「〇〇に行ってきた日」形式。AI音声（tts.py）の1文ごとに1カットを割り当て、文が始まる `lead` 秒前でカットする。
- 演出：
  - 丸ゴシックの字幕
  - 時刻チップ（AM 9:00 など）
  - 1カット目にタイトルのステッカーと小さなロゴ
  - カットの頭に軽いズーム（パンチイン）
  - 明るいエンドカード。最後の行（導線）を読む間に CTA の丸ボタンが出る
- 既定のBGMは `lofi`（ナレーション中は自動で下がる）。
- 目安の長さ：8〜9文で約24秒（tempo 1.15、間 0.25〜0.4秒）。

```json
"vlog": {
 "taste": "vlog",
 "title": "美容鍼に行ってきた日",          // 1カット目のステッカーとエンドカードの手書きメモ
 "start": 0.30, "gaps": [0.30, 0.38, ...], // 最初の文の開始秒、各文のあとの間（"gap": 0.32 で一括も可）
 "lead": 0.18,                              // 文の何秒前でカットするか
 "sub_y": 0.88,                             // 字幕の高さ（セーフゾーン内の割合）
 "duration": 24,                            // 省略すると、最後の文のあと約2.6秒で終わる
 "voice": {"engine": "aivis", "speaker": 497929760, "tempo": 1.15, "aliases": {"見本": "ミホン"}},
 "bgm": {"style": "lofi"},
 "lines": [
  {"sub": ["今日は、ずっと気になってた", "美容鍼の日。"],   // 字幕（1〜2行）
   "speech": "今日は、ずっと気になってた、びようばりの日。", // 読み上げる文（難読語はかな）
   "chip": "AM 9:00",                                      // 任意：時刻チップ
   "sub_pos": 0.25,                                        // 任意：この行だけ字幕の位置を変える（顔を避ける）
   "shot": {"clip": "IMG_1460 2.mov", "in": 1.1, "zoom": [1.12, 1.18], "center": [0.45, 0.45], "shake": 7}},
  ...,
  {"sub": ["ご予約はリンクから。"], "speech": "ご予約は、リンクから。", "card": true}  // 最後の1行だけ card: true
 ]
}
```
- 書く順番：
  1. 文を書く
  2. `tts.py` を実行する
  3. 静止画で確認する（tts.py の前でも、文字数から長さを見積もって確認できる）
- 文は「行動→場所→体験→気持ち→導線」の順に並べる。映像と内容がずれないようにする（施術中に「終わったら」と言わない）。
