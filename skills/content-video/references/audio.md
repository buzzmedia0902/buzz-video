# BGM・効果音・音量（finish.py）

`finish.py` が、声を映像と同じ位置で切り、BGMを作曲し、効果音を置き、-14 LUFS に整えて書き出す。設定はトンマナの標準＋ version の上書き。

## BGM（毎回オリジナルを作曲。サンプルや既存曲は使わない）
| style | 中身 | 既定のトンマナ | 声との差（BGMの大きさ） |
|---|---|---|---|
| `lofi` | エレピ、ゆるいドラム、レコードのノイズ | 信頼・解説 | 14dB下 |
| `acoustic` | ナイロンギター、マリンバ、シェイカー | 親しみ・やわらか | 15dB下 |
| `pop` | シンセのはじく音、明るいフック、ハウスのキック | バラエティ | 12dB下 |
| `wa` | 琴、三味線、尺八風、笙、和太鼓（スマホでも聞こえる78〜150Hz） | 和・重厚 | 15dB下 |
| `ambient` | パッド、まばらな音、空気感。ドラムなし | 洗練・ミニマル | 18dB下 |
| `piano` | フェルトピアノ＋パッド | （上書き用） | — |
| `none` | BGMなし | — | — |
- どの長さでも作れる（4秒〜20分）。8小節ごとにコードとメロディを作り直すので、長くても同じ部分のくり返しにならない。
- タイトル・終了画面のカードで盛り上がり、終了画面で着地する。話の間（無音）では少し上がる。
- 21dB下では「BGMがない」と感じられた。迷ったら14dB下。
- 上書き：version に `"bgm": {"style": "pop", "music_db": -12}`。Vlogは `"bpm": 100` と `"snap": "beat"` でクリップの長さを拍に合わせる（曲もそのテンポで t=0 から始まる）。和の雰囲気は `"mood": "bright"`（陽音階）か `"calm"`（都節・既定）。
- 同じ構成で別の曲にしたいときは `finish.py --seed 2`。

## 効果音
| set | 主な音 | トンマナ |
|---|---|---|
| `soft` | シュッ（見出し）、ポン（カード）、ドン（強調）、カチッ（名札） | 信頼・解説 |
| `cute` | ポップ、キラキラ | 親しみ・やわらか |
| `variety` | ほぼすべての要素に音 | バラエティ |
| `wa` | 和太鼓（見出し・強調）、拍子木（タイトル） | 和・重厚 |
| `none` | なし | 洗練・ミニマル |
- 音はトンマナの draw 要素から自動で置かれる。version に `"sfx": false` で全部なし。

## 声
- 映像と同じ範囲を切り、つなぎ目に12msのフェード。1.1倍速などは rubberband で音程を変えずに速くする。
- 高域・低域の整理と軽いコンプレッサー。雑音が大きい素材だけノイズ除去をかける。
- Vlog などの `clip` の音は、既定で小さく残す（`audio: duck`）。会話を聞かせるなら `keep`、消すなら `mute`。

## 仕上がりの数値
- 全体 -14 LUFS、True Peak は AAC に変換したあとで -1 dBTP 以下（変換で上がる分を測ってから下げ直す）。
- `work/<version>/report_<比率>.json` に、声とBGMの差・リミッターのかかり具合・字幕の表示時間などが入る。

## 聞けないことを伝える
- 私（Claude）は音を聞けない。数値（音量・ピーク・声の聞き取り）は確認するが、曲の好み・効果音の量は、最初の1本をユーザーに聞いてもらって調整する（BGMの大きさ・曲調・効果音の量を選択式で聞く）。
- 素材の中で流れている音楽（店内BGM・テレビ）は Content ID に引っかかる可能性がある。報告に書く。
