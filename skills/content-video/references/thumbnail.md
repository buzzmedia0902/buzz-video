# サムネ・カバー（thumb.py）

YouTube本編は1280×720のサムネを3案（「テストと比較」に3つまで入れられる）、ショート・切り抜き・Vlogは1080×1920のカバーを2案作る。見た目は version のトンマナに合わせる。

## 使い方
```bash
"$PY" "$S/thumb.py" edit.json --version main --scan          # 顔の候補一覧（work/thumbs/<version>/faces.jpg）だけ作って見る
"$PY" "$S/thumb.py" edit.json --version main \
    --copy "AIで変わる｜{動画編集}｜{10選}" --line "これ、｜{手作業やめよ！}" --sub "編集の時間、ほぼゼロに" \
    --badge "経営者｜{AI導入}｜の現場から" --before "手作業｜8時間" --after "AI｜10分"
"$PY" "$S/thumb.py" edit.json --version main --copy "…" --times 67.6 33.0 82.8   # 顔のコマを秒で指定（案の順）
```
- 出力：`<out_dir>/サムネ/`。`<version>_feed.jpg` はスマホのフィードの大きさ（640・360・168px）で並べた確認用。必ず見る。
- 文字：`｜`で改行、`{ }`が目立つ色。`--before` / `--after` / `--thing` は文字（`ラベル｜値`）、画像ファイル、`素材id@秒` のどれでも。

## 3つの方向（YouTube）
1. **リアクション**：本人の実際の一言（`--line`）を吹き出しに、表情の大きい顔。
2. **ビフォーアフター**：同じものの ✕ → ○（`--before` / `--after` がないときは作らない）。
3. **権威**：肩書きバッジ（`--badge`）＋大きなコピー＋自信のある笑顔。
YouTubeの「テストと比較」は総再生時間で勝者を決め、決まらないと最初にアップロードしたものが全員に出る。いちばん自信のある案を1番目にする。

## 守ること（ユーザーから学んだこと）
- 顔は全編を1.5秒ごとに調べ、目が開いて表情があり、手がぶれていないコマを選ぶ（faces.jpg を見て `--times` で差し替え）。
- 切り抜きの人物には白い10pxのフチ＋細い黒フチ。
- フィードの小ささ（168px）でも読める文字の大きさ（バッジは約70px）。
- 右下は再生時間の表示に隠れるので空ける。半分隠れた要素を置かない。
- タイトルと同じ言葉を繰り返さない（サムネとタイトルで役割を分ける）。
- 言葉は本人が動画で実際に言ったものを使い、肩書きや実績は事実を確認する（例：番組での立場が「審査する側」か「出演した側」か、現在か以前か）。
