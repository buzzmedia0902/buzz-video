# 用途ごとの組み立て

どの用途も「parts（並べる部品）＋ overlays（重ねる要素）＋ cues（字幕）」で作る。トンマナは見た目とテンポだけを変える。

## YouTube本編（format: youtube, 16:9）
**構成**：冒頭ダイジェスト（5〜15秒）→ タイトル（2秒）→ 本編（ジェットカット）→ 山場で締める → 終了画面（6秒前後）。
- 冒頭ダイジェスト：本編で一番強い一言・場面を `clip` で2〜4個（同じ部分を本編でもう一度使ってよい）。声から始めず、映像と文字で始める型もある（トンマナの title カード）。
- タイトル：`{"kind": "card", "card": "title", "dur": 2.2}`。ロゴは brand.logo、文字は brand.channel か part の text。
- 本編：`talk` で全体を入れ、言い直し・NGは `remove`。長い話は10分前後になるよう章ごとに整理する（長さの質問に従う）。
- 見出し（chapter）：話題が変わるところに置く。概要欄のチャプターになる（最初は0:00、3つ以上、各10秒以上）。
- 図解カード（card）：数字・手順・用語の一覧。早口で並べた言葉は、1つずつ出すより2〜4個を1枚にまとめて残す。
- 強調ワード（emphasis）：1分に1〜2回まで。使いすぎると効かない。
- 最後：話が尻すぼみで終わるなら、一番いい締めの一言で切る。終了画面はアニメーションの高評価・チャンネル登録（下の方はYouTubeの終了画面要素のために空けてある）。
- 納品：本編、軽量版（720p）、字幕.srt、概要欄.txt（説明＋チャプター）、サムネ3案。

## ショート・リール（format: short, 9:16）
**構成**：最初の1秒で何の話か分かる → 1つの話題だけ → 最後の一言で締める（60秒以内が目安）。
- タイトル帯（version の `title`）が上にずっと出る。2行以内、強調は `{ }`。
- 横の素材は「顔を中心に切り取る（cover）」が既定。2人以上が映る素材は `"fit": "band"`（帯で置く）。
- カードは縦画面では「背景ぼかし＋顔の丸窓＋中央のカード」になる。
- 長い動画から作るときは、話の切れ目（文の終わり）で始めて終える。途中から始まるなら、最初の字幕を聞こえる部分だけにする。
- 納品：動画、軽量版、カバー画像、投稿文（タイトル・本文・ハッシュタグ）。

## 切り抜き（format: clip, 9:16 が既定）
**構成**：タイトル帯（何が起きたか）→ 16:9の番組映像を帯で中央に → 大きな字幕（話者ごとに色）→ 出典表記。
- 候補探し：`"$PY" "$S/find.py" edit.json --src ep --who 山田 --grep 出資` で、話者・キーワード・盛り上がりから30〜75秒の候補を出す。URLは `find.py --download URL`（yt-dlp。権利者の許可がある動画だけ。取れないときは yt-dlp を更新するか、ファイルをもらう）。
- 話者：`speakers.py` で声から判定。名札は一人に出たままのことがあり、名札＝話者ではない。判定できない行は話者なし（中立の色）。
- タイトルは主語がはっきり分かる書き方にする（例：「新人に“論破された”社長／その新人がまさかの役員に！？」。「論破された社長が役員に」では、役員になったのが社長だと読めてしまう）。
- 番組がカットしていて言葉の途中で映像が切れる場合は、声を残して映像を止める（`clip` を2つに分け、間を同じ画の短い `clip` でつなぐ）。
- 切り抜きのルール：番組・チャンネルの切り抜きガイドラインと申請フォームを確認するよう、報告に必ず書く。
- 納品：本数分の動画とカバー、投稿文、出典の確認事項。

## 日常Vlog（format: vlog, 9:16）
**構成**：1日・1イベントの流れ。音楽に合わせてクリップをつなぎ、場所や気持ちを短い caption で添える。
- parts は `clip` を並べ、それぞれ `"dur"`（出力の秒）で長さを決める。`"snap": "beat"` で曲の拍に合わせる（テンポは `"bgm": {"bpm": 100}`）。
- 横の素材も画面いっぱいに切り取る（Vlogの既定は cover）。見せたい位置は `"center": [x, y]`、看板や他社ロゴが入るなら `zoom` と `center` で外す。
- 素材の音は既定で小さく残す（duck）。会話を聞かせたいクリップは `"audio": "keep"` にする。字幕は keep の部分にだけ出る（duck / mute の部分の会話は字幕にならない）。
- 音楽が流れている素材（クルーズ船・店内など）は `"audio": "mute"`（著作権のある曲）。
- 24コマ・iPhoneの可変コマの素材でカクつくときは、その clip に `"smooth": true`。
- 投稿文は delivery.md の型で Claude が書く。
- 写ってほしくない人（一般の人、支援を受ける人など）が映る部分は使わない。
- 冒頭3秒で一番いい画を見せる。最後はロゴか一言で締める。
- 納品：動画、軽量版、カバー画像、投稿文。

## 1つの素材から複数本作る
本編（youtube）とショート数本（short）を同じ edit.json の versions に並べる。字幕（cues.json）・話者・顔の位置は共通で使える。ショートは本編と別の切り口（強い一言から始める）にする。
