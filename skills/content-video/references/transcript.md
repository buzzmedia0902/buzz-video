# 文字起こし・字幕・話者

## 手順
```
"$PY" "$S/transcribe.py" edit.json [--src talk] [--max-chars 16]   # 話している区切りごとに Whisper → cues.json（下書き）
# cues.json を直す
"$PY" "$S/transcribe.py" edit.json --align                         # 直した文に合わせて時刻を付け直す（元は cues.json.bak）
"$PY" "$S/speakers.py" edit.json --src ep                          # 複数人のとき：声で話者を判定
```
- まとめて文字起こしすると時刻が最大1秒ずれ、無音で「ご視聴ありがとうございました」などの幻聴が出る。transcribe.py は区切りごとに聞き取り、短い区切りの定番の幻聴は捨てる。
- 騒がしい素材でも同じ文を繰り返すループが起きにくい（`-mc 0`）。

## 直し方（cues.json）
- **固有名詞・数字**：社名・人名・サービス名・製品名（例：クロードのオーパス5.5 → Claude Opus 5.5）。分からない名前は推測で書かず、聞こえたとおりにして報告で確認する。確認できない人名は字幕に出さない（その行を直すか `"cut": true`）。
- **使わない行**：Vlog などで音を出さない部分の行は消してよい（字幕は声が聞こえる部分にしか出ないが、残すと編集のときに紛らわしい）。
- **聞き間違い**：前後の意味から明らかなものだけ直す。2つの候補で迷う助詞・語尾（も／また、なんよ／なんや）は、字幕から外す。
- **強調**：言いたいことの核を `{ }` で囲む（1字幕に1か所まで）。
- **言いよどみ**：「えー」「あの」「まあ」は字幕から自動で外れる（声は残る）。字幕に出したくない行は `"cut": true`。
- **言い直し・NG**：声ごと消すときは、その秒数を part の `remove` に入れる（字幕も自動で消える）。
- 1行に入れる長さ：縦14〜16字、横18〜20字。長い行はエンジンが単語の切れ目で2行に分ける（英語名・「ん」の前では切らない）。`｜` で改行位置を指定できる。

## 字幕のルール（エンジンが守る）
- 1.2秒以上表示（前後の無音に伸ばす、または同じ話者・同じ部品の隣の行とつなぐ。合計40字まで）。
- 冒頭ダイジェストなど同じ言葉が2回出るときは、両方に字幕が出る。部品の端にかすっただけの行は出さない。
- 見出し（chapter）は2.3秒以上。

## 話者の判定（speakers.py）
- edit.json の `speakers` に、話者ごとの色と、本人だけがはっきり話している区間（`refs`、2〜4か所）を書く。
- 声の特徴（ECAPA）で各行を照合し、十分に近く、2番目の候補と差があるときだけ話者を付ける。笑い声・かぶった声・短い相づちは付けない。
- **名札や映っている人から推測しない**。番組の名札は一人に出たままのことがあり、怒鳴っている別の人の発言を取り違えた例がある。
- 元動画のテロップの色が話者ごとに決まっている番組は、補助の手がかりに使う。
- どちらとも言えない行は話者なしのまま（中立の色）にして、報告に書く。

## 話している区間の検出
- 150〜4000Hzのエネルギーで判定し、しきい値は録音ごとに自動で決まる（静かな部分＋12dB）。
- 環境音が大きい素材でカットが不自然なときは、part に `"pause"` を大きめにする（例：0.5）。
