# 仕上げのチェック

## 自分で見るもの（比率ごと）
`render.py ... --sheet 0.5 --guides` で一覧を作り、気になる瞬間は `--stills` で大きく見る。
- [ ] 最初の1秒：明るい画面で、何の店か分かるか（ロゴかフックの一言が出ているか）
- [ ] テロップと字幕：黄色の枠に収まっているか、顔にかかっていないか、1.2秒以上出ているか、誤字がないか
- [ ] ぼかし：他社ロゴ・POP・画面・名札・一般客の顔・機器メーカーのロゴや機種名が、**その比率で切り取った範囲の中で**ぼけているか
- [ ] 閃光：レーザーなどの1コマだけの光が残っていないか（`flash_guard`。最後は完成した動画で、施術カットをコマ送りして確認）
- [ ] ロゴの読みやすさ：淡い色のロゴや白いテロップが、明るい壁・窓の上で消えていないか
- [ ] 上下逆さの素材が正しい向きになっているか。不自然な拡大で画質が落ちていないか
- [ ] エンドカード：ロゴ・導線が収まり、導線が2秒以上出ているか。ロゴの色が変わっていないか
- [ ] 16:9 のぼかし背景：中央の素材と文字が読みやすいか
- [ ] トーク画面：ステータスバー・時刻の順序・キーボードの配列が実機どおりか

## 数字で見るもの（finish.py が書く `work/<version>/report_<比率>.json`）
| 項目 | 合格の目安 |
|---|---|
| `duration` | 構成表と同じ |
| `frames` | 長さ × 30 |
| `lufs` | -15〜-13 |
| `true_peak` | -1.0 以下 |
| `dup_seconds` | エンドカードより前に、同じコマが3回以上続く秒がない（あれば30fps素材のスローか、範囲外の素材を疑う） |
| `size_mb` | 書き出し本体は広告の入稿上限（Meta は 4GB）以内 |
| `light_mb` | 30MB 未満（スマホ共有用） |

単体で確かめるときは `"$PY" "$S/qa.py" 納品/xxx.mp4 --until <card_at>`。

## 別のエージェントにレビューを頼む（生成とチェックは分ける）
作った本人は見落としやすい。Agent ツールで次のように依頼する。渡すのは静止画のパスと構成表で、こちらの結論は渡さない。

```
SNS広告動画のレビューをお願いします。業種：<業種>。配信先：<Meta広告／TikTok／通常投稿>。
静止画（比率ごと）：<work/review/... のパス一覧>
構成表：<project.json のパス>（テロップ・ナレーションの文言は lines / captions にあります）
次の3点を、時刻と具体的な直し方つきで、重要な順に挙げてください。
1. 広告規制・審査のリスク：<業種の規制>（効果効能、ビフォーアフター、体験談、No.1、個人の特徴に触れる表現）、他社ロゴ・個人情報の映り込み
2. 見え方：テロップが顔やセーフゾーン外にかかっていないか、読める時間か、比率ごとの切り取りの破綻、最初の1秒の強さ
3. 日本語：誤字、不自然な言い回し、ナレーションと映像のずれ（「終わったら」が施術中に流れる、など）
問題がない項目は「問題なし」と書いてください。
```
指摘はうのみにしない。静止画で確かめてから直す。直したら、該当する比率だけ書き出し直す。

## 過去の案件で実際に指摘されたこと
- 鍼のアップで始まる → Meta の審査で刺激的と判断されるおそれ。年齢制限を推奨した。
- 治療中に笑っているカット → 「痛くない」と受け取られる。落ち着いた表情に差し替えた。
- ナレーションと映像のずれ → 「終わったら」が施術中に流れていた。行とカットを合わせた。
- 導線が1秒しか出ない → 2秒以上に延ばした。
- 暗いフェードインで始まる → 最初のコマを明るくし、ロゴを出した。
- トーク画面のキーボードのかなの位置、時刻が戻る、上の空白 → 実機どおりに直した。
