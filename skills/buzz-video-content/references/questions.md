# 最初の質問（選択式）

素材を一通り見てから AskUserQuestion で聞く。ユーザーはスマホで選択肢を押して答えることが多い。
- 選択肢は2〜4個（「その他」は自動で付くので入れない）、説明は1行
- 素材と目的に合うものを先頭に置き、ラベルの末尾に「（おすすめ）」を付ける
- チャットですでに決まっている項目（「縦で」「60秒で」「バラエティっぽく」）は聞き直さない。1回目の4問がすべて決まっていれば、1回目は出さずに2回目だけ聞く

## 1回目（4問まとめて）

### Q1 用途
- header: `用途`
- question: `どんな動画にしますか？`

| label | description |
|---|---|
| YouTube本編 | 横・5〜20分。カット・テロップ・図解・見出し・終了画面まで |
| ショート・リール | 縦・60秒前後。上にタイトル帯、大きな字幕 |
| 切り抜き | 長い動画から名場面を抜き出す。話者ごとに色分け |
| 日常Vlog | 複数のクリップを音楽に合わせてつなぐ |

おすすめ：横のトーク素材が長い → YouTube本編、縦のトーク → ショート、配信・番組・対談 → 切り抜き、話の少ない複数クリップ → 日常Vlog。複数作るとき（本編＋ショート）は multiSelect にする。

### Q2 トンマナ
- header: `トンマナ`
- question: `どんな雰囲気（トンマナ）にしますか？`

5つのうち素材と目的に合う4つを出す（残りは「その他」で選べると説明に書かない。聞かれたら案内する）。

| label | description |
|---|---|
| 信頼・解説 | 白い太字＋黄色の強調、見出しと図解。ビジネス・ノウハウ向け |
| 親しみ・やわらか | 丸文字の吹き出し、話者ごとのパステル色。人柄・対談・日常向け |
| バラエティ・勢い | 色フチの字幕、心の声、強調ワードと効果音多め。エンタメ向け |
| 和・重厚 | 金の筆文字のタイトル、楷書の字幕、和太鼓。投資番組・対談の山場など勝負の場面向け |
| 洗練・ミニマル | 細い文字で控えめ、間を生かす。ブランド・高価格帯向け |

作り比べたいと言われたら multiSelect にして、同じ素材で2つのトンマナの version を作る。

### Q3 比率
- header: `比率`
- question: `どの比率で書き出しますか？（複数可）` / multiSelect

| label | description |
|---|---|
| 9:16 縦 | ショート・リール・TikTok |
| 16:9 横 | YouTube本編 |
| 1:1 正方形 | フィード・LINE VOOM |
| 4:5 縦長 | Instagram／Facebookのフィード |

用途から決まるとき（YouTube本編→16:9、ショート→9:16）は聞かずに決めてよい。そのときは Q3 を「長さ」の詳細か Q5 以降の1問に差し替える。

### Q4 長さ
- header: `長さ`

用途ごとに選択肢を変える。

| 用途 | 1（おすすめ） | 2 | 3 |
|---|---|---|---|
| YouTube本編 | おまかせ（話をすべて生かし、間だけ詰める） | 10分前後に整理 | 5分前後のダイジェスト |
| ショート・切り抜き | 60秒以内 | 30秒以内 | 90秒前後 |
| 日常Vlog | 30秒前後 | 60秒前後 | 15秒（ティザー） |

## 2回目（当てはまる質問だけ。最大4問）

### Q5 参考動画
- header: `参考動画`
- question: `寄せたい動画はありますか？`

| label | description |
|---|---|
| なし（型のまま）（おすすめ） | 選んだトンマナの標準で作る |
| URLを送る | 好きなチャンネルの動画。テロップ・テンポ・音の大きさを測って寄せる |
| 過去の自分の動画 | 以前の投稿に合わせる（ファイルかURLを送ってもらう） |

「URLを送る」を選んだら、次のメッセージでURLを貼ってもらい、`ref_probe.py` を実行する。

### Q6 テロップの量
- header: `テロップ`
- question: `テロップ（字幕）はどれくらい入れますか？`

おすすめは用途で変える：YouTube本編・ショート・切り抜き →「全部字幕」、日常Vlog →「要点だけ」（声を聞かせる場面と、場所・気持ちの一言だけ）。

| label | description |
|---|---|
| 全部字幕（おすすめ） | 話したことをすべて字幕に。音なしで見られても伝わる |
| 要点だけ | 強調したい言葉と見出し・図解だけ |
| なし | タイトルと名札だけ |

「要点だけ」は cues.json で残す行以外に `"cut": true` を付け、emphasis と card を増やす。

### Q7 テンポ
- header: `テンポ`
- question: `テンポはどうしますか？`

| label | description |
|---|---|
| 型に合わせる（おすすめ） | トンマナの標準の間の詰め方 |
| もっと速く | 間をさらに詰め、1.1倍速にする |
| ゆったり | 間を残し、等速 |

「もっと速く」は version に `"cut": {"pause": 0.25, "speed": 1.1}`、「ゆったり」は `"cut": {"pause": 0.6}`。画面の動きは増やさない。

### Q8 サムネ（YouTube本編のとき）／BGM（それ以外）
- サムネ：question `サムネは何案作りますか？`、`3案（テストと比較用）（おすすめ）` / `1案` / `いらない`
- BGM：question `BGMの雰囲気は？（すべてオリジナル曲を作曲します）`、`トンマナに合わせる（おすすめ）` / `明るくポップ` / `落ち着いたピアノ` / `BGMなし`

### Vlogのとき（Q6〜Q8のどれかと入れ替える）
- header: `素材の音`、question: `素材の会話や音は残しますか？`
  - `いい会話だけ残す（おすすめ）`：聞かせたい一言だけ音を出し字幕を付ける。ほかは音楽を主役に
  - `音楽だけ`：素材の音は消す
  - `環境音も少し残す`：雰囲気として小さく残す
- 写ってよい人も確認する：一般の人・子ども・同乗者などが映る素材は、使ってよいか、ぼかすかを聞く（選択肢：`身内だけなので全部OK` / `一般の人は使わない（おすすめ）` / `ぼかして使う`）

## 聞かずに決めてよいもの
次の項目は素材とトンマナから決め、最後の報告で伝える（差し替えられることも書く）。
- タイトル帯の文言・見出し・図解カードの中身（話の内容から案を作る）
- 強調する言葉（{ } で囲む）
- 書き出しの順番（まず1本を仕上げて共有し、残りを続けて作る）
