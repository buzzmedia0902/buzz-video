# 仕上げのチェック

## 自分で見るもの
`render.py ... --sheet 3` で一覧、気になる瞬間は `--stills`。比率ごとに見る。
- [ ] 最初の1秒で何の動画か分かる（タイトル帯・強い一言・映像）
- [ ] 字幕：2行以内、顔にかからない、誤字・固有名詞・数字が正しい、話者の色が正しい
- [ ] カード・名札・強調ワードが顔にかかっていない（縦のカードは背景ぼかし＋顔の丸窓）
- [ ] 見出しの文言が話と合っている。チャプターが概要欄の条件を満たす（0:00始まり・3つ以上・各10秒以上）
- [ ] 画面の寄り引きが多すぎない（10秒以上あける。ズームは40秒に1回程度）
- [ ] 映ってはいけないもの（一般の人の顔、他社ロゴ、PC・スマホの画面、個人情報）が出ていない
- [ ] 終わり方：山場や締めの一言で終わり、だらだら続かない。終了画面のボタンが動く
- [ ] 縦動画：右側のボタン列・下の説明文の位置（下25%）に大事な文字がない

## 数字で見るもの（finish.py が書く `work/<version>/report_<比率>.json`、単体は `qa.py`）
| 項目 | 合格の目安 |
|---|---|
| `lufs` | -15〜-13 |
| `true_peak` | -1.0 以下 |
| `frames` | 長さ × fps |
| 字幕の最短表示 | 1.2秒以上（1.2秒未満が0件） |
| 字幕の文字の速さ | 95%が1秒あたり8文字以下 |
| 1分あたりの画面切り替え | トンマナの目安以内（信頼・解説で6回前後） |
| 同じコマの連続 | エンドカード以外で続かない（スローや変換の不具合） |

## 別のエージェントにレビューを頼む（作った本人は見落とす）
Agent ツールで依頼する。渡すのは静止画のパス・構成表・字幕で、こちらの結論は渡さない。

```
発信用動画のレビューをお願いします。用途：<YouTube本編／ショート／切り抜き／Vlog>。トンマナ：<…>。
次のファイルを見て、問題だけを箇条書きで返してください（良い点は不要）。
- 静止画：<work/review/... の一覧とパス>
- 構成表：<edit.json>、字幕：<cues.json>、出力の字幕：<work/<version>/cues_out.json>
見てほしい点：
1. 誤字・固有名詞・数字・話者名の誤り（話者名は公開後に問題になるので特に）
2. 顔・大事な被写体にかかる文字やパネル、画面端で切れている文字
3. 字幕の改行位置（単語の途中・英語名の途中で切れていないか）、読む時間が足りない字幕
4. 見出し・カードの内容が話と合っているか、誇張や誤解を招く表現がないか
5. 映ってはいけないもの（一般の人、他社ロゴ、画面、個人情報）
6. 最初の1秒で何の話か分かるか、終わり方が締まっているか
指摘には、時刻（秒）と、どう直すべきかを付けてください。
```

## これまでの指摘（同じことを繰り返さない）
- 画面が動きすぎて見づらい → 寄り引きは10秒以上あける、ズームは少なく
- テロップが短くて読めない → 1.2秒以上、早口の言葉の並びはカード1枚にまとめる
- BGMと効果音がなくて単調 → BGMは声の約14dB下、効果音は見出し・カードに
- 説明パネルが顔にかかった → 顔を避けて置く、小さくする、最後に透過
- 話者名の取り違え → 声で照合、怪しい行は話者なし
- 終わり方が微妙 → 山場で終えて、アニメーションの高評価・登録で締める
